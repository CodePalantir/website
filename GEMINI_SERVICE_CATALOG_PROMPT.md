## 3. DESIGN LANGUAGE & BRAND GUIDELINES

### Color Palette
**Primary:**
- Purple Gradient: `#8E2DE2` → `#4A00E0` (signature brand gradient)
- Slate 900: `#0F172A` (primary dark text)
- White: `#FFFFFF` (backgrounds, contrast)

**Secondary:**
- Purple 600: `#9333EA` (accents)
- Purple 50: `#FAF5FF` (light backgrounds)
- Slate 600: `#475569` (body text)
- Slate 400: `#94A3B8` (subtle text)
- Slate 50: `#F8FAFC` (section backgrounds)

**Accent Colors (for service categories):**
- Emerald/Green for "success" states
- Red for "warning/deprecated" states
- Yellow for "moderate" states

### Typography
**Primary Font:** Plus Jakarta Sans (modern, clean, technical)
- Headings: Bold (700-800 weight), tight tracking
- Body: Regular (400-500 weight), relaxed line-height
- Monospace font for code/technical elements

**Hierarchy:**
- Page titles: 48-72pt, bold, tight leading
- Section headers: 32-40pt, bold
- Service titles: 18-24pt, semibold
- Body copy: 12-14pt, regular, 1.6-1.8 line-height
- Small labels: 8-10pt, uppercase, wide tracking (tracking: 0.15-0.2em)

### Visual Style
- **Modern minimalism** with technical precision
- **Rounded corners** (16-32px border radius) on cards
- **Subtle shadows** (soft, layered shadows for depth)
- **Grid-based layouts** (clean, Swiss design influence)
- **Whitespace-heavy** (breathing room, not cramped)
- **Icons:** Lucide icon style (stroke-based, minimal, 2px stroke weight)

### Design Elements
- Purple gradient badges/tags for emphasis
- Code block aesthetics (dark terminal windows, syntax highlighting feel)
- Metric visualization (progress bars, percentage displays)
- Card-based service presentation
- Subtle decorative elements (rotated rectangles, gradient overlays at ~10% opacity)

### Voice & Tone
**Direct. Technical. Confident.**
- No fluff or marketing speak
- Problem-focused headlines (call out pain points)
- Solution-oriented descriptions
- Quantifiable outcomes where possible
- Engineering precision in language
- Avoid: "best in class", "world-class", generic claims
- Embrace: Specific technical terms, honest problem diagnosis, clear outcomes

## 6. DESIGN EXECUTION GUIDELINES

### Visual Principles
✅ **DO:**
- Use generous whitespace (min 40px margins)
- Maintain consistent 8px grid system
- Use purple gradient sparingly for emphasis only
- Include subtle shadows for depth (0 4px 12px rgba(0,0,0,0.08))
- Use icons consistently (Lucide style, 24px size)
- Maintain visual hierarchy through size, weight, color
- Use card-based layouts with rounded corners (16-24px)

❌ **DON'T:**
- Cram too much text (keep descriptions concise)
- Use more than 3 font weights
- Use bright, saturated colors outside brand palette
- Use stock photos or generic imagery
- Use decorative elements that don't add meaning
- Create cluttered layouts

### Typography Scale
- Page headlines: 48-56pt, bold
- Section headers: 32-36pt, semibold
- Service titles: 18-20pt, semibold
- Body text: 12-14pt, regular
- Captions/labels: 10-11pt, medium
- Small text: 8-9pt, uppercase, wide tracking

### Iconography
Use Lucide icon library style:
- 2px stroke weight
- 24px default size
- Purple accent color (#8E2DE2) or slate for neutral
- Consistent with website design

### Call-to-Action Design
- Primary CTA: Purple gradient background, white text, 16px padding, rounded 12px
- Secondary CTA: White background, purple border 2px, purple text, same padding/rounding
- Hover state: Subtle shadow lift or opacity change
